# Blank

> "No hago nada. Y lo hago bien." — Este repo

## ¿Qué es esto?

Un repositorio que no hace absolutamente nada. Y lo hace con una dedicación admirable.

## Características

- ✅ No hace nada
- ✅ Tampoco hace nada en otros idiomas
- ✅ Compatible con todos los sistemas operativos (no hace nada en todos)
- ✅ Sin dependencias (no necesita nada para no hacer nada)
- ✅ Open source (porque no hay nada que ocultar)
- ✅ Licencia LIP (Licencia de Inutilidad Pública)

## Instalación

```bash
git clone https://github.com/Lucianopm24/blank.git
cd blank
# Ya está. No hay nada más que instalar.
# De nada.
```

## Uso

```bash
cat hola.txt        # Saluda
cat adios.txt       # Despídete
cat filosofia.txt   # Contempla el universo
cat 404.txt         # Piérdete
node nada.js        # Ejecuta la nada
python nada.py      # Ejecuta la nada, pero con clase
```
